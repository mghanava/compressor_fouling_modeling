Bayesian Model Evaluation: Understanding Uncertainty and Metrics

This guide explains the two types of uncertainty in Bayesian regression models, how to properly assess noise model calibration, and why certain empirical checks are valid while others are not.

1. The Regression Model

Assume a standard regression model:

$$y \sim \mathcal{N}(\mu, \sigma)$$ $$\mu = \mathcal{f}\left(X, \beta \right) = \beta_{0} + \beta_{1} \cdot X_{1} + \beta_2 \cdot X_{2} + \ldots$$

2. Two Types of Uncertainty

TypeNameDescription
1Posterior Uncertainty (Epistemic)Uncertainty about the model parameters ($\theta$)
2Observation-Level Prediction Uncertainty (Aleatoric)Variability in predictions across different observations

3. Posterior vs. Posterior Predictive

3.1 Posterior: $\text{trace.posterior}[\mu]$

The deterministic mean function (expected value): $\mu = E[y \mid X, \theta]$

  • No random noise included
  • Pure systematic component
  • Each draw: $\mu_{d} = \mathcal{f}\left(X, \beta_{d} \right)$ where $d$ indexes the posterior draw

3.2 Posterior Predictive: $\text{trace.posterior\_predictive}[y_{obs}]$

The full predictive distribution including observation noise:

$$y_{pred} \sim \mathcal{N}(\mu, \sigma)$$ $$y_{pred} = \mu + \sigma \cdot \epsilon \qquad \text{where} \quad \epsilon \sim \mathcal{N}(0, 1)$$
  • Stochastic predictions (includes observation noise)
  • Full data-generating process
  • Each draw represents a complete observation (signal + noise): $y_{d} = \mathcal{f}\left(X, \beta_{d} \right) + \sigma_{d} \cdot \epsilon_{d}$
Note: The random seed provided for sampling matters — without it, a particular draw can produce different noise values.

4. Variance and Expected Value Decomposition

4.1 Total Variance

$$\text{Var}\left(y_{pred}\right) = \text{Var}\left(\mu\right) + \text{Var}\left(\sigma \cdot \epsilon\right) = \text{Var}\left(\mu\right) + \sigma^2$$
ComponentUncertainty TypeDescription
$\text{Var}(\mu)$EpistemicParameter uncertainty / explained variance
$\sigma^2$AleatoricIrreducible noise / unexplained variance
$\text{Var}(y_{pred})$TotalTotal predictive uncertainty

4.2 Expected Value

$$E[y_{pred}] = E[\mu + \sigma \cdot \epsilon] = E[\mu] + \sigma \cdot E[\epsilon] = E[\mu] + \sigma \cdot 0 = \mu$$

5. Why Not Use Posterior Predictive for Empirical Residuals?

Important: We should NOT use posterior predictive samples to calculate empirical residuals for noise model checking.

5.1 The Problem

$$y_{pred} - y_{obs} = \left(\mu_{posterior} + \sigma_{posterior} \cdot \varepsilon_{pred}\right) - \left(\mu_{true} + \sigma_{true} \cdot \varepsilon_{obs}\right)$$

This decomposes as:

$$= \text{systematic error} + \text{noise}_{pred} - \text{noise}_{obs}$$

5.2 Why This Is Wrong

$$\text{Var}(y_{pred} - y_{obs}) = \text{Var}(\mu_{posterior} - \mu_{true}) + \sigma_{posterior}^2 + \sigma_{true}^2$$

If $\sigma_{posterior} \approx \sigma_{true} \approx \sigma$:

$$\text{Var}(y_{pred} - y_{obs}) \approx \text{Var}(\text{systematic error}) + 2\sigma^2$$

The variance is inflated by $2\sigma^2$ — we're mixing posterior uncertainty with observation noise.

5.3 The Correct Approach

Use only posterior uncertainty (the mean function):

$$\mu_{posterior} - y_{obs} = \mu_{posterior} - \left(\mu_{true} + \sigma_{true} \cdot \varepsilon_{obs}\right) = \text{systematic error} - \text{noise}_{obs}$$

Now the variance is clean:

$$\operatorname{Var}(\mu_{posterior} - y_{obs}) \approx \operatorname{Var}(\text{systematic error}) + \sigma_{true}^2$$
Key Insight: By using $\mu_{posterior} - y_{obs}$ instead of $y_{pred} - y_{obs}$, we avoid double-counting noise and get an unbiased estimate of the true noise level.

6. Raw σ vs. Model σ

Important: The raw $\sigma$ (dotted line in diagnostic plots) includes BOTH between-setpoint variance AND within-setpoint noise, while the model $\sigma$ estimates only the within-setpoint noise after accounting for the mean function $\hat{\mu}$.

6.1 Decomposition

$$\sigma_{\text{raw}} = \sqrt{\sigma^2_{\mu} + \sigma^2_{\epsilon}}$$ $$\sigma_{\text{model}} = \sigma_{\epsilon}$$

Where:

  • $\sigma^2_{\mu}$ = variance explained by the mean function (between-setpoint)
  • $\sigma^2_{\epsilon}$ = residual variance (within-setpoint measurement noise)

6.2 Calibration Criteria

$$\sigma_{\text{model}} = E[\sigma \mid \text{data}]$$ $$\sigma_{\text{residual}} = \text{SD}(y - \hat{\mu})$$ $$\text{Ideal calibration:} \quad \sigma_{\text{model}} \approx \sigma_{\text{residual}}$$
For ideal calibration: The model $\sigma$ should capture the residual noise after accounting for $\mu$, NOT match the raw $\sigma$!

7. Bayesian R² and Posterior Uncertainty

7.1 Why Use Posterior Uncertainty?

Bayesian R² asks: "What is the distribution of R² values given my uncertainty about the parameters?" It's fundamentally about model uncertainty, not individual predictions.

7.2 Formula

For a given posterior draw indexed $d$, the fraction of variability explained by the model's mean function:

$$R^2 = \frac{\mathrm{Var}\left(\mu_d \right)}{\mathrm{Var}\left(\mu_d \right) + \mathrm{Var}\left(y_{obs}-\mu_d \right)}$$
