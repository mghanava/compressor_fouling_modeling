Bayesian LOO Diagnostics and Expected Log Pointwise Predictive Density (ELPD)

This guide explains how to evaluate Bayesian model predictive performance using Leave-One-Out cross-validation (LOO-CV) and the Expected Log Pointwise Predictive Density (ELPD). It covers both the theoretical foundations and practical diagnostic checks for model calibration.

1. Definition of ELPD-LOO

The Expected Log Pointwise Predictive Density using LOO cross-validation is:

$$\text{elpd\_loo} = \sum_{i=1}^{n} \log p(y_i \mid y_{-i})$$

where:

  • $y_i$ is observation $i$
  • $y_{-i}$ represents all observations except observation $i$
  • $p(y_i \mid y_{-i})$ is the posterior predictive density for $y_i$ when trained on all data except $y_i$

This metric quantifies how well the model predicts held-out observations, providing an estimate of out-of-sample predictive performance.

2. Mathematical Foundations

2.1 Normal Likelihood Log-Density

For a Normal likelihood, the log-density of a single observation is:

$$\log p(y_i \mid \mu, \sigma) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{1}{2}\left(\frac{y_i - \mu}{\sigma}\right)^2$$

2.2 Relationship Between ELPD and Model Precision

For a well-calibrated model with unbiased predictions, the expected log-density simplifies to:

$$\mathbb{E}[\log p] = -\frac{1}{2}\log(2\pi) - \log(\sigma) - \frac{1}{2} = -0.919 - \log(\sigma) - 0.5$$

This shows that smaller $\sigma$ (more precise predictions) leads to higher log-likelihood:

2.3 RMS Standardized Residual from ELPD

Rearranging in terms of the average LOO log-density, we can back-solve for the root-mean-square (RMS) standardized residual:

$$\left|\frac{y - \mu}{\sigma}\right|_{\text{RMS}} = \sqrt{2\left(-\frac{1}{2}\log(2\pi\sigma^2) - \overline{\text{loo}}_{\log}\right)}$$

For a perfectly calibrated Normal model, the RMS z-score should be close to 1.0.

4. Analytical Log-Density Calibration Check

4.1 Method

To visualize calibration, we compute the "ideal" per-observation log-density under perfect calibration (RMS z-score = 1) across all posterior draws of $\sigma$:

$$\ell_{\text{ideal}}(\sigma) = -\frac{1}{2}\log(2\pi) - \log(\sigma) - \frac{1}{2}$$

This yields a distribution of ideal log-densities reflecting posterior uncertainty in $\sigma$. We then overlay the actual average LOO log-density to see where it falls.

5. Pointwise ELPD Analysis

5.1 Exponentiating to Density Scale

For individual observations, we exponentiate the pointwise LOO log-densities:

$$p(y_i \mid y_{-i}) = \exp(\text{elpd}_i)$$

5.2 Reference Lines

  • Geometric mean LOO density ($\exp(\overline{\text{elpd}})$): Actual average out-of-sample performance
  • Expected density under perfect calibration: Theoretical density if every observation had RMS z-score = 1.0
  • The gap between these represents the out-of-sample prediction penalty

5.3 Interpreting Pointwise Scatter

PositionMeaning
Above reference linesObservation easy to predict ($|z| < 1$)
Near reference linesAbout as surprising as a typical Normal draw
Below reference linesObservation hard to predict ($|z| > 1$)

5.4 Expected Distribution of z-scores

Even for a perfectly calibrated model:

  • ~38% of observations: $|z| < 0.5$ → high density (above lines)
  • ~30%: $0.5 < |z| < 1.0$ → near the lines
  • ~24%: $1.0 < |z| < 2.0$ → below the lines
  • ~8%: $|z| > 2.0$ → well below the lines

7. Effective Number of Parameters

The $p_{\text{loo}}$ represents the effective number of parameters, accounting for:

  • The actual number of parameters
  • The degree to which priors constrain the posterior
  • The effective complexity used to fit the data
Rule of thumb: Observations per parameter $= n / p_{\text{loo}} \gtrsim 5$ indicates sufficient data to support model complexity.

8. Pareto $k$ Diagnostics

The reliability of the LOO estimate is assessed using Pareto $k$ diagnostics:

RangeStatusInterpretation
$k \leq 0.70$GoodLOO approximation reliable
$0.70 < k \leq 1.00$BadPotentially influential point; investigate
$k > 1.00$Very BadLOO approximation unreliable for this point
Note: With 98%+ observations having $k \leq 0.70$, the overall LOO estimate is considered reliable.

10. Conclusion

All diagnostics converge on the same finding: a well-calibrated Bayesian model should show:

  1. RMS z-score ≈ 1.0 — Predictive distributions neither too narrow nor too wide
  2. LOO log-density within analytical distribution — Out-of-sample performance consistent with posterior uncertainty
  3. Homogeneous pointwise scatter — No systematic miscalibration across observed values
  4. 98%+ Pareto $k \leq 0.70$ — LOO approximation reliable

The leave-one-out predictive performance should closely match the analytically expected log-density, with only a minor and expected out-of-sample penalty.
